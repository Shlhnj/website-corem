---
title: "How to post an update to this site"
---

This is a sample post showing the format for news items. To publish a real update:

1. Add a new file to `_posts/` named `YYYY-MM-DD-a-short-title.md`.
2. Give it a front matter block with a `title:`.
3. Write the update in Markdown below the front matter.

Jekyll picks up any file in `_posts/` automatically and lists it on the homepage and the [News](/news/) page, newest first.

*Delete this post once the team is comfortable with the workflow.*
